# ADR-0007 — One OpenAPI 3.0 document generates Go and TypeScript HTTP types

**Status:** Accepted, 2026-09-26

## Context
With the cloud in Go, request/response shapes could drift between the desktop (TypeScript) and the server. The IPC
contract already has a single source (the zod registry); HTTP needed one too.

## Decision
`packages/contracts/openapi/muneem-v1.yaml` is the HTTP contract. `oapi-codegen` generates `cloud/api/openapi.gen.go`
(gitignored, regenerated by `make gen`); `openapi-typescript` generates `packages/contracts/src/http/generated.ts`.
The document is OpenAPI **3.0.3**: `oapi-codegen` does not fully support 3.1 and no 3.1 feature was needed.

## Consequences
- A shape change is one edit, then both sides fail to compile until updated.
- CI must run the generators before building (see the `make gen` steps in `.github/workflows/ci.yml`).
